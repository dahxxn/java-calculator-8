# java-calculator-precourse

## 🔢 문자열 덧셈 계산기

### 🔷 기능 요구사항 정리

---

| **구분**    | **기능명**               | **세부 설명**                                                              |
|-----------|-----------------------|------------------------------------------------------------------------|
| **입력**    | **문자열 입력**            | 사용자로부터 “덧셈할 문자열을 입력해 주세요.” 라는 안내문과 함께 문자열을 입력받는다                       |
| **구분자**   | **구분자 목록 생성**         | 기본 구분자 `,` 와  `:` 을 포함한 구분자 목록을 생성한다                                   |
|           | **커스텀 구분자 감지**        | 입력 문자열의 앞부분이 `//` 로 시작하고 `\n` 으로 끝나는, 커스텀 구분자 양식인지 확인한다                |
|           | **커스텀 구분자 추가**        | 커스텀 구분자가 확인된 문자를 구분자 목록에 추가한다                                          |
| **숫자 추출** | **구분자 기준 파싱**         | 커스텀 구분자 확인 이후, 구분자 목록에 있는 문자들을 기준으로 문자열을 자른다                           |
|           | **숫자 변환**             | 검증된 자른 문자(토큰)를 숫자 형식으로 변환한다                                            |
| **검증**    | **커스텀 구분자 양식에 대한 검증** | 커스텀 구분자가 오는 영역에 공백 포함 한 개 이상의 문자를 두는 경우, 잘못된 입력으로 처리한다                 |
|           | **커스텀 구분자 양식에 대한 검증** | 커스텀 구분자가 오는 영역에 숫자가 오는 경우, 잘못된 입력으로 처리한다                               |
|           | **숫자 변환 과정에 대한 검증**   | 자른 문자(토큰)이 숫자로만 구성되어 있지 않고 다른 문자가 있는 경우, 잘못된 입력으로 처리한다                 |
| **예외처리**  | **잘못된 입력에 대한 예외 처리**  | 검증 과정에서 잘못된 입력으로 처리되면, `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료된다 |
| **계산**    | **덧셈 누적 계산**          | 추출한 숫자는 `result` 에 누적 더하여 계산한다                                         |
| **출력**    | **결과 출력**             | `결과 : <result>` 형식으로 덧셈 결과를 출력한다                                       |

> 위 표는 기능 구현 목록을 담습니다. 프리코스 진행 방식에서 제시된 “기능 요구사항에 기재되지 않은 내용은 스스로 판단하여 구현한다”에 해당하는 내용은 아래 **이렇게 판단했습니다** 에 기재했습니다.
>

<br></br>

### 🤔 이렇게 판단했습니다

---

- **커스텀 구분자**는 `//` 와 `\n` 사이의 **공백 없는 단일 문자**만 허용했습니다
    - 과제 원문 명세의 “커스텀 구분자는 문자열 앞부분의 `//`와 `\n` 사이에 위치하는 **문자**를 사용한다”를 우선 준수했습니다.
    - **허용 예:** `//;\n1;2;3`
    - **비허용 예:** `//ab\n1ab2`

- 숫자는 **10진수로 해석**하며 **선행 0을 허용**합니다
    - **예**: "012" → 12
